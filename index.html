          Google client

          Your own Google project's sign-in details. Set them once; Google Drive and Google Calendar both use them.

          How do I get these? (one-time setup)
          1. Open console.cloud.google.com and create a project (call it anything, e.g. “IB Tracker”).
          2. APIs & Services → Library → enable Google Drive API.
          3. OAuth consent screen (“Google Auth Platform”): choose External, add your email, add the scope drive.appdata, then press Publish app so sign-in doesn't expire after 7 days.
          4. Credentials → Create credentials → OAuth client ID → type Web application.
          5. Under “Authorized redirect URIs” add http://127.0.0.1:53682/callback
          6. Under “Authorized JavaScript origins” add the address of your hosted page (for this page that is ).
          7. Copy the client ID (and, for the Mac app, the client secret) into the boxes above. Use the same client on every device so they share one cloud file.
